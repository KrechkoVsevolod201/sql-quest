# SQL Quest

**SQL Quest** — локальная игровая площадка для обучения SQL. Запускается в Windows одним файлом, открывается в браузере и использует только Python из стандартной библиотеки и SQLite.

## Быстрый запуск (Windows)

1. Установи Python 3.10 или новее с [python.org](https://www.python.org/downloads/windows/) и включи опцию **Add Python to PATH**.
2. Дважды щёлкни `start.bat` или запусти в PowerShell:

   ```powershell
   py -3 sql_game.py
   ```

3. Приложение откроется по адресу <http://127.0.0.1:8765>. Чтобы остановить, нажми `Ctrl+C` в открытом окне.

Пакеты через `pip` устанавливать не нужно. Если порт занят: `py -3 sql_game.py --port 8766`.

## Возможности

- **Учебный маршрут:** 13 модулей от основ SELECT и фильтрации до CTE, оконных функций и операций над множествами; 32 задания распределены по темам.
- **Рабочая область задания:** компактный выбор темы и упражнения, условие, SQL-редактор и схема БД рядом; связи и внешние ключи показаны явно.
- **Проверка результата:** запрос запускается на read-only копии учебной базы; результат сравнивается с эталоном без требования к порядку строк. Запрос ограничен 500 строками и временем выполнения 1,2 секунды.
- **Режимы:** практика, таймер на 2 минуты, рекорд скорости и оптимизация. Опыт зависит от первого прохождения, режима и личного рекорда; задания дня дают дополнительный XP.
- **Прогресс:** опыт, уровни, серия дней, ежедневный квест, история решений и агрегированная скорость SQL.
- **SQL-лаборатория:** собственная изолированная база, сохраняемая между перезапусками приложения; выполнение DDL/DML в режиме подготовки и запросов — в режиме исследования. Доступны время выполнения, число строк и статистика запусков.
- **Необязательный ИИ:** генерация схем/данных/задач, проверка AI-квеста с наградой +30 XP и педагогическая оценка SQL через совместимый с OpenAI Chat Completions API.
- **Генератор в «Учиться»:** создаёт случайный квест или квест по теме и сложности; SQL Quest исполняет схему, seed и эталон в изолированной SQLite-базе и показывает задание только после успешной проверки ответа.
- **MCP:** локальный stdio MCP-сервер с инструментами для просмотра учебных баз, запуска SQL, проверки ответа, генерации задач и разбора запроса.

## LM Studio и MCP

Базовые уроки работают без сети. Для локальной нейросети:

1. В LM Studio открой **Developer**, загрузи instruct-модель и нажми **Start Server**.
2. Запусти SQL Quest, открой **Настройки AI** в боковом меню.
3. Проверь адрес API (по умолчанию `http://localhost:1234/v1`), нажми **Проверить соединение**, выбери модель и сохрани настройки.
4. Используй генератор квестов во вкладке «Учиться», AI-конструктор в лаборатории или кнопку разбора SQL.

API-ключ необязателен, если локальный сервер его не требует. Адрес, модель и необязательный ключ сохраняются в локальной базе SQL Quest; API-ключ не возвращается в UI после сохранения. Чтобы стереть ключ, отметь «Удалить сохранённый API-ключ» и сохрани настройки.

Для headless-режима и MCP можно использовать переменные окружения:

```powershell
$env:SQL_GAME_API_KEY = "твой-api-ключ"
$env:SQL_GAME_BASE_URL = "https://api.openai.com/v1" # необязательно
$env:SQL_GAME_MODEL = "gpt-4o-mini"                  # необязательно
py -3 sql_game.py
```

`SQL_GAME_BASE_URL` должен содержать корень API, к которому добавится `/chat/completions`. Сохранённые через UI настройки используются и MCP-сервером; при отсутствии сохранённой конфигурации он использует переменные окружения.

Запуск MCP-сервера из папки проекта:

```powershell
py -3 mcp_server.py
```

Он общается по JSON-RPC через stdio и предоставляет tools: `list_learning_databases`, `run_sql`, `grade_exercise`, `review_sql_with_ai`, `generate_exercise`. Подключи команду `py -3 <полный-путь-к-проекту>\mcp_server.py` как локальный stdio MCP-сервер в своём MCP-клиенте. Для AI-tools задай ключ в окружении этого процесса.

HTTP API приложения (все запросы выполняются только на `127.0.0.1`):

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/dashboard`, `/api/modules`, `/api/databases`, `/api/exercises` | Игровые данные |
| GET | `/api/exercises/{id}`, `/api/schema?database=shop` | Задание и схема |
| POST | `/api/run`, `/api/grade`, `/api/complete` | Выполнение и проверка |
| GET/POST | `/api/lab/schema`, `/api/lab/template`, `/api/lab`, `/api/lab/grade`, `/api/lab/complete` | Лаборатория и AI-квесты |
| POST | `/api/ai/review`, `/api/ai/generate` | AI-функции |
| GET/POST | `/api/ai/challenges`, `/api/ai/challenge` | AI-квесты: список и генерация новой базы с проверенным эталоном |

## Хранение данных

Базы, прогресс и лаборатория хранятся в автоматически создаваемой папке `data/`:

- `shop.sqlite3`, `library.sqlite3`, `games.sqlite3` — учебные наборы;
- `sql_quest.sqlite3` — профиль, опыт и история;
- `laboratory.sqlite3` — пользовательская песочница.
- `generated/` — отдельные базы созданных AI-квестов.

Резервную копию профиля можно сделать, скопировав `data/`. Чтобы начать заново, сначала закрой приложение и удали `data/sql_quest.sqlite3`; чтобы пересоздать песочницу, удали `data/laboratory.sqlite3`. Учебные базы создаются при первом запуске и не перезаписываются автоматически.
